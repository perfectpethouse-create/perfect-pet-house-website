# วิธีแก้ให้ "จองแล้วมีเมลแจ้ง + ลง Google Calendar" ✅

## ปัญหาที่เจอ (สรุปให้เข้าใจง่าย)

ข้อมูลจองจากเว็บ**ส่งถึง Google สำเร็จมาตลอด** แต่สคริปต์ฝั่ง Google
**ไม่มีสิทธิ์ส่งอีเมล** (ยังไม่เคยกด "อนุญาต" ให้สคริปต์ใช้ Gmail)
ระบบเลยพังเงียบๆ — ลูกค้าเห็นว่าจองสำเร็จ แต่ร้านไม่ได้รับอะไรเลย

ข้อความ error จริงที่ระบบตอบกลับมา:
> Exception: คุณไม่ได้รับอนุญาตให้เรียกใช้ MailApp.sendEmail

## ขั้นตอนแก้ (ทำครั้งเดียว ~10 นาที)

### ขั้นที่ 1 — เปิดโปรเจกต์ Apps Script เดิม

1. เข้า **https://script.google.com** (ล็อกอินด้วยบัญชี Google ของร้าน — บัญชีเดียวกับที่สร้างสคริปต์นี้ไว้)
2. เปิดโปรเจกต์ที่เคยสร้างไว้สำหรับรับข้อมูลจองจากเว็บ

### ขั้นที่ 2 — วางโค้ดใหม่

1. ลบโค้ดเดิมในไฟล์ `รหัส.gs` (Code.gs) ออกทั้งหมด
2. เปิดไฟล์ **`booking-notify.gs`** (อยู่โฟลเดอร์เดียวกับคู่มือนี้) คัดลอกโค้ดทั้งหมดไปวางแทน
3. กด 💾 บันทึก (Cmd+S)

> โค้ดใหม่ทำอะไรเพิ่ม: ส่งเมลแจ้งร้าน + **ลงคิวใน Google Calendar อัตโนมัติ**
> (อาบน้ำตัดขน = ลงเป็นคิว 2 ชม. / ฝากเลี้ยง = ลงเป็นแถบยาวตั้งแต่วันรับเข้าถึงวันรับกลับ)
> และถ้าอยากเก็บประวัติจองลง Google Sheet ให้ใส่ Sheet ID ที่บรรทัด `SHEET_ID`

### ขั้นที่ 3 — กดอนุญาตสิทธิ์ (ขั้นสำคัญที่สุด — ที่ผ่านมาพังเพราะข้ามขั้นนี้)

1. ที่แถบบนของ editor เลือกฟังก์ชัน **`testAuthorize`** จากเมนู dropdown
2. กดปุ่ม **▶ เรียกใช้ (Run)**
3. จะมีหน้าต่างขึ้นมาขอสิทธิ์ → กด **ตรวจสอบสิทธิ์ (Review permissions)**
4. เลือกบัญชี Google ของร้าน
5. ถ้าขึ้นหน้า "Google ยังไม่ได้ยืนยันแอปนี้" → กด **ขั้นสูง (Advanced)** → **ไปที่โปรเจกต์ (unsafe)** (ปลอดภัย เพราะเป็นสคริปต์ของเราเอง)
6. กด **อนุญาต (Allow)** — สคริปต์ขอสิทธิ์: ส่งอีเมล + จัดการปฏิทิน (+ Sheet ถ้าตั้งค่า)
7. ✅ เช็คผล: จะมี**เมลทดสอบ**เข้า perfectpethouse@gmail.com และมี**คิวทดสอบ**โผล่ใน Google Calendar วันนี้ 10:00 น. (ลบทิ้งได้เลย)

### ขั้นที่ 4 — อัปเดต deployment (สำคัญ: ห้ามสร้าง deployment ใหม่!)

ต้องอัปเดตของเดิมเพื่อให้ **URL คงเดิม** (เว็บชี้ไปที่ URL นี้อยู่):

1. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** มุมขวาบน → **จัดการการทำให้ใช้งานได้ (Manage deployments)**
2. กดไอคอน **✏️ ดินสอ (แก้ไข)** ที่ deployment ที่ใช้งานอยู่
3. ช่อง **เวอร์ชัน (Version)** → เลือก **เวอร์ชันใหม่ (New version)**
4. ตรวจว่า:
   - **เรียกใช้ในนาม (Execute as):** ฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
5. กด **ทำให้ใช้งานได้ (Deploy)**

### ขั้นที่ 5 — ทดสอบจริง

1. เปิดเว็บร้าน แล้วลองจองอาบน้ำตัดขน 1 รายการ (ใส่ชื่อ "ทดสอบ")
2. เช็คว่า:
   - 📧 มีเมลแจ้งเข้า perfectpethouse@gmail.com
   - 📅 มีคิวโผล่ใน Google Calendar ตามวัน/เวลาที่เลือก
   - ✅ หน้าเว็บขึ้น "ส่งคำขอจองให้ร้านเรียบร้อยแล้ว ✓"

## ของใหม่ที่ผมแก้ให้ฝั่งเว็บแล้ว (deploy เว็บรอบหน้าได้เลย)

- หน้าเว็บ**เช็คผลจริง**ก่อนบอกลูกค้าว่า "ส่งสำเร็จ" — ถ้าระบบขัดข้องจะบอกลูกค้าให้ทักไลน์/โทรแทน (เดิมขึ้นว่าสำเร็จทั้งที่ไม่สำเร็จ)
- แอปมือถือมีสถานะแจ้งว่า "✓ ส่งข้อมูลถึงระบบร้านเรียบร้อย" หรือเตือนให้กดส่ง LINE ถ้าระบบล่ม
- กันลูกค้าเลือก**วันย้อนหลัง** และวันรับกลับก่อนวันรับเข้า
- ตรวจ**เบอร์โทร**ต้องเป็นตัวเลข 9–10 หลักก่อนส่ง
- เพิ่ม security headers ฝั่งเซิร์ฟเวอร์ (กัน clickjacking / MIME sniffing)

## ถ้ามีปัญหา

- เมลไม่เข้า → เช็คถังสแปม แล้วรัน `testAuthorize` ซ้ำดู error ใน "การดำเนินการ (Executions)" เมนูซ้ายของ Apps Script
- URL เปลี่ยน (เผลอสร้าง deployment ใหม่) → ส่ง URL ใหม่มาให้ Claude อัปเดตในเว็บ (อยู่ 2 จุด: `index.html` และ `app.html` ตัวแปร `GOOGLE_SCRIPT_URL`)
