# วิธีติดตั้ง "ระบบลงทะเบียนเข้าพัก" 🏨🐾

> ระบบนี้ **แยกจากระบบจองเดิมทั้งหมด** — คนละ Apps Script คนละ Google Sheet
> ระบบจองที่ใช้งานได้อยู่จะไม่ถูกแตะเลย ทำตาม 6 ขั้นนี้ครั้งเดียว (~15 นาที)

หน้าเว็บฟอร์มพร้อมแล้วที่ **perfectbkk.com/checkin.html** (ลิงก์ส่งตรงให้ลูกค้า — ไม่โชว์ในเมนู)
เหลือแค่ "ต่อท่อ" ให้ข้อมูลไหลเข้า Google Sheet + อีเมล ตามขั้นตอนนี้

---

## ขั้นที่ 1 — สร้าง Google Sheet ใหม่

1. เข้า **https://sheets.google.com** (ล็อกอินบัญชี Google ของร้าน)
2. สร้างสเปรดชีตเปล่า 1 อัน ตั้งชื่อ **"PPH ทะเบียนเข้าพัก"**
3. ดู **Sheet ID** จาก URL ของชีต — คือส่วนที่อยู่ระหว่าง `/d/` กับ `/edit`
   ```
   https://docs.google.com/spreadsheets/d/  1AbCdEf...ThisIsTheID...xyz  /edit
                                            └──────── คัดลอกส่วนนี้ ────────┘
   ```
   > หัวตาราง (48 คอลัมน์) ระบบจะสร้างให้อัตโนมัติเองในการส่งครั้งแรก — ไม่ต้องพิมพ์เอง

---

## ขั้นที่ 2 — สร้างโปรเจกต์ Apps Script ใหม่

1. เข้า **https://script.google.com** → กด **โปรเจกต์ใหม่ (New project)**
2. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) เป็น **"PPH ลงทะเบียนเข้าพัก"**
3. ลบโค้ดเดิมในไฟล์ `รหัส.gs` (Code.gs) ออกทั้งหมด
4. เปิดไฟล์ **`checkin-notify.gs`** (อยู่โฟลเดอร์เดียวกับคู่มือนี้) คัดลอกทั้งหมดไปวางแทน
5. กด 💾 บันทึก (Cmd/Ctrl + S)

---

## ขั้นที่ 3 — ใส่ Sheet ID

1. ในโค้ดที่วางไว้ หาบรรทัด (อยู่ช่วงบนๆ ในกล่อง `CONFIG`):
   ```js
   SHEET_ID: '',   // ⚠️ ใส่ ID ของ Google Sheet ใหม่ "PPH ทะเบียนเข้าพัก" ตรงนี้
   ```
2. วาง Sheet ID จากขั้นที่ 1 ลงในเครื่องหมายคำพูด ให้เป็น:
   ```js
   SHEET_ID: '1AbCdEf...ThisIsTheID...xyz',
   ```
3. กด 💾 บันทึกอีกครั้ง

---

## ขั้นที่ 4 — กดอนุญาตสิทธิ์ (ขั้นสำคัญที่สุด! ห้ามข้าม)

> ระบบจองเดิมเคยพังเพราะข้ามขั้นนี้ — สคริปต์ต้องได้รับสิทธิ์ "เขียนชีต + ส่งอีเมล" ก่อน

1. ที่แถบบนของ editor เลือกฟังก์ชัน **`testAuthorize`** จากเมนู dropdown
2. กดปุ่ม **▶ เรียกใช้ (Run)**
3. หน้าต่างขอสิทธิ์ขึ้นมา → กด **ตรวจสอบสิทธิ์ (Review permissions)** → เลือกบัญชี Google ของร้าน
4. ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" → กด **ขั้นสูง (Advanced)** → **ไปที่โปรเจกต์ (unsafe)** (ปลอดภัย เป็นสคริปต์ของเราเอง)
5. กด **อนุญาต (Allow)**
6. ✅ เช็คผล: จะมี **1 แถวทดสอบ** โผล่ในชีต "PPH ทะเบียนเข้าพัก" + **อีเมลทดสอบ** เข้า perfectpethouse@gmail.com
   → ลบแถวทดสอบทิ้งได้เลย

---

## ขั้นที่ 5 — Deploy เป็น Web App แล้วคัดลอก URL

1. มุมขวาบน กด **ปรับใช้ (Deploy)** → **การปรับใช้ใหม่ (New deployment)**
2. กดไอคอนเฟือง ⚙️ ข้าง "เลือกประเภท" → เลือก **แอปเว็บ (Web app)**
3. ตั้งค่า:
   - **ดำเนินการในนามของ (Execute as):** ฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** ← สำคัญ! ไม่งั้นเว็บส่งข้อมูลไม่ได้
4. กด **ปรับใช้ (Deploy)** → คัดลอก **URL แอปเว็บ** ที่ลงท้ายด้วย `/exec`
   ```
   https://script.google.com/macros/s/AKfycb..................../exec
   ```

---

## ขั้นที่ 6 — เอา URL มาใส่ในหน้าเว็บ

1. เปิดไฟล์ **`public/checkin.html`**
2. หาบรรทัด (อยู่ช่วงต้นของ `<script>`):
   ```js
   var CHECKIN_SCRIPT_URL = 'PASTE_YOUR_CHECKIN_APPS_SCRIPT_URL_HERE';
   ```
3. วาง URL `/exec` จากขั้นที่ 5 แทนข้อความ placeholder:
   ```js
   var CHECKIN_SCRIPT_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
   ```
4. บันทึก แล้ว **commit + push** ขึ้น main → เว็บ perfectbkk.com/checkin.html จะใช้งานได้จริงใน ~1 นาที
   (ให้ Claude ช่วย commit/push ได้เลย)

---

## เสร็จแล้ว! ทดสอบจริง

1. เปิด **perfectbkk.com/checkin.html** บนมือถือ ลองกรอก 1 ตัว แล้วกดส่ง
2. เช็ค: มีแถวใหม่ในชีต + อีเมลแจ้งเข้าร้าน (เลขบัตรโชว์แค่ 4 ตัวท้ายในอีเมล — ในชีตเก็บเต็ม)
3. ถ้ากรอกอีเมลลูกค้าด้วย จะมีอีเมลยืนยันส่งถึงลูกค้าอัตโนมัติ

## เกร็ดสำคัญ

- **แก้โค้ดครั้งหลัง** (เช่นเพิ่มอีเมลแจ้งเตือน): หลังแก้ ต้องกด **ปรับใช้ → จัดการการปรับใช้ (Manage deployments) → ✏️ แก้ไข → เวอร์ชันใหม่ → ปรับใช้** เพื่อให้ URL เดิมใช้โค้ดใหม่ (อย่าสร้าง deployment ใหม่ ไม่งั้น URL เปลี่ยน)
- **ความเป็นส่วนตัว (PDPA):** ชีตนี้มีเลขบัตรประชาชนเต็ม — แนะนำจำกัดสิทธิ์แชร์ชีตเฉพาะทีมงานที่จำเป็น อย่าตั้งเป็น "ทุกคนที่มีลิงก์"
- **แก้กฎระเบียบ:** เนื้อหากฎในสเต็ปยินยอมอยู่ในฟังก์ชัน `rulesHTML()` ของ `checkin.html` (อ้างอิงฉบับเต็มที่ `apps-script/กฎระเบียบและนโยบาย-เข้าพัก.md`)
